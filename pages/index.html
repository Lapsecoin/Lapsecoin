Run a node

Use a pre-built binary from the releases page. Building from source needs native libraries (liboqs, chiavdf) that can be awkward to compile.

chmod +x lapsecoin && ./lapsecoin     # Linux
lapsecoin.msi                         # Windows (double-click)

You are asked for a signing passphrase, then the wallet is at http://localhost:8335. For headless setups, set LAPSECOIN_PASSPHRASE and pass --no-gui.

PortInterfacePurpose
83330.0.0.0Peer traffic (UDP) and the public read-only node UI and API (TCP). Safe to expose. Set with --port.
8335127.0.0.1Private wallet UI, including Send. Never expose. Defaults to port + 2.

How it works

Consensus
The chain with the most cumulative proven VDF work wins, Bitcoin-style. Ties go to the lower VDF output.
Transactions
Ordinary and plaintext, with sender-bid fees and an optional memo of up to 200 bytes.
Supply
Capped at 21 million LAPSE and released on a smooth exponential curve. 1 LAPSE is 100,000,000 ticks.
Addresses
Twelve BIP39 words derived from the public key. Creating one needs no node.
Source
github.com/Lapsecoin/core. The README has every CLI option and setting.
